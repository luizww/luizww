## 🦉 Meu laboratório: Luma

Estou desenvolvendo a **Luma**, um chat operacional para trabalhar com produtos, anúncios e tarefas de e-commerce.

É onde estudo, na prática, como conectar IA a ferramentas e serviços, acompanhar tarefas e manter as regras de negócio na aplicação. O projeto envolve backend, banco de dados, uma Bridge e integrações com marketplaces.
